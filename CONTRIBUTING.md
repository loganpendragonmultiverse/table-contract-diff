# Contributing

Contributions are welcome through reviewed pull requests. Open an issue first for scope-changing work. Install `.[dev]`, add focused tests, and run `ruff format --check .`, `ruff check .`, `mypy src`, `pytest`, `python -m build`, and `python -m pip_audit .` before submitting.

Pull requests must explain the user problem, approach, limitations, and security or privacy impact. Automated checks do not replace maintainer review. Use synthetic fixtures and never include credentials, private documents, production captures, or customer data.
